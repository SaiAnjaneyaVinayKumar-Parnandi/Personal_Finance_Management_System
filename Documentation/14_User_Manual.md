## Purpose

The purpose of this User Manual is to provide end users with guidance for using the Personal Finance Management System (PFMS). It explains the application features, navigation, and operational procedures required for efficient day-to-day usage.

---

## Scope

This document covers the usage of all functional modules available in the Personal Finance Management System (PFMS).

The scope includes:

- Application Navigation
- Dashboard
- Master Management
- Budget Management
- Reserve Management
- Hard Cash Wallet
- Financial Transactions
- Operational Logs
- Insurance
- Investments
- Loans
- Utilities
- Reports
- General Usage Guidelines

This document does not describe database design, APIs, deployment procedures, system architecture, or source code implementation.

## Application Overview

The Personal Finance Management System (PFMS) is designed to help users manage personal finances by maintaining master data, recording financial transactions, tracking operational expenses, monitoring budgets, maintaining investments and loans, and generating financial reports.

## General Usage Guidelines

Users should follow these guidelines while using the application:

- Maintain accurate master data.
- Verify financial transaction details before saving.
- Record operational expenses promptly.
- Review dashboard summaries regularly.
- Maintain updated investment, loan, and insurance information.
- Generate reports periodically for financial analysis.

## Frequently Asked Questions

### How do I record a financial transaction?

Navigate to **Financial Transactions**, enter the required details, and save the transaction.

### Can I export reports?

Yes. Reports can be exported from the Reports module.

### Can I update previously recorded information?

Yes. Most business records can be updated using their respective modules.
